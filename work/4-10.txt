# Git 사용자 정보 설정 - 공용 컴퓨터에서의 고려사항

## 짧은 답
**사용자 정보는 설정해도 되지만, 기본 브랜치는 신중해야 합니다.**

---

## 자세한 설명

### 1️⃣ **사용자 정보 (user.name, user.email)**

#### ✅ 설정해도 괜찮은 이유
- **로컬 설정**으로 해당 컴퓨터에만 적용됩니다
- 커밋 기록에 당신의 이름이 올바르게 남습니다
- 다른 사용자에게 직접적인 영향이 없습니다

#### ⚠️ 주의할 점
```bash
# 전역 설정 (공용 컴퓨터에서는 피하기)
git config --global user.name "홍길동"
git config --global user.email "hong@example.com"

# 각 프로젝트마다 설정 (권장)
git config user.name "홍길동"
git config user.email "hong@example.com"
```
- 전역(`--global`)으로 설정하면 다른 사용자가 그 설정을 사용할 수 있습니다
- **프로젝트별로 설정**하는 것이 안전합니다

---

### 2️⃣ **기본 브랜치 (init.defaultBranch)**

#### ⚠️ 피해야 하는 이유
- 팀 전체의 워크플로우에 영향을 줍니다
- 다른 팀원이 예상하지 못한 브랜치로 작업할 수 있습니다
- 공용 컴퓨터에서 설정하면 다음 사용자도 그 설정을 사용합니다

#### ✅ 올바른 방법
```bash
# 팀 전체가 합의한 후, 저장소 설정으로 통일
# .git/config 또는 README에 문서화
```

---

## 정리

| 항목 | 공용 컴퓨터 | 방법 |
|------|-----------|------|
| **사용자 정보** | ✅ 가능 | 프로젝트별 설정 (`--global` 제외) |
| **기본 브랜치** | ❌ 피하기 | 팀 협의 후 저장소 설정으로 통일 |

**결론**: 사용자 정보는 프로젝트별로 설정하고, 기본 브랜치는 팀 리더나 관리자에게 문의하세요! 🙂
